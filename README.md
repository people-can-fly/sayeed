# Sayed Abu Sayeed: research website

A one-page academic website for GitHub Pages. It has no build step and no outside services; the fonts are stored in the `fonts/` folder.

## Put it online (about 10 minutes)

1. Sign in to GitHub and create a **new public repository** named exactly `YOUR-USERNAME.github.io` (use your real GitHub username).
2. On the new repository page, click **Add file → Upload files**.
3. Drag in `index.html`, `README.md` and the whole `fonts` folder. Click **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment", set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then **Save**.
5. After 1–2 minutes the site is live at `https://YOUR-USERNAME.github.io`.

To change anything later, open `index.html` on GitHub, click the pencil icon, edit and commit. The site updates by itself.

## Finish these before sharing

Search `index.html` for `TODO` and `DRAFT`.

- [ ] **Google Scholar**: the link currently runs a name search. Replace it with your profile URL (it appears twice).
- [ ] **LinkedIn**: add your profile URL and remove the comment markers around that line.
- [ ] **"Where this work is going"**: this paragraph is a draft written from your publication list. Rewrite it in your own words so it matches your actual research plan.
- [ ] **Your role on co-authored papers**: under each co-authored paper there is a spot for a line such as `<p class="related">My role: designed the risk metrics and ran the analysis.</p>`.
- [ ] **Code and data (optional)**: if you put code, datasets or prototypes on GitHub, uncomment the "Code and data" section near the bottom and add the links.
- [ ] **CV (optional)**: upload a PDF named `cv.pdf` and add `<li><a href="cv.pdf">CV (PDF)</a></li>` to the links under your name. Consider removing your phone number from the public copy.

## What's in the folder

- `fonts/`: Archivo and Source Serif 4, self-hosted under the SIL Open Font License (license files included)
